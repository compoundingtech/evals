# agent-new-confirmation-contract

This model-free cell freezes the safe DQ1 fallback while autonomous interview
commit is not admitted. A valid semantic intent is rendered and summarized, but
the final bundle cannot be published until the human explicitly confirms that
summary. Rejection, EOF, a clean `pty attach` detach (Ctrl+\), or an externally
delivered SIGINT/exit 130 retires the temporary declaration, retains its
tombstone, and publishes no final declaration. Because attach runs the terminal
in raw mode, a terminal Ctrl-C byte (`0x03`) is forwarded to the managed session
and is not local cancellation. Merely having a valid intent is not commit
authority.

This cell does not claim that autonomous no-confirmation behavior is accepted.
