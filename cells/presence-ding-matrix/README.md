# presence-ding-matrix

Model-free end-to-end DING coverage against an isolated deterministic PTY consumer. The real st2 sidecar
proves busy and away delivery, fresh-DND suppression, stale-DND derivation to unknown, FIFO resumption, and
retention of a failed transport head before its queued follower. All temporary processes use the eval's PTY
partition and are explicitly removed.
