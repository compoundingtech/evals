# vrs-definition-of-done — matched governance-document variation

This cell is one half of a matched experiment. The paired conditions use the same task, Sonnet 5 medium
seat, fixture code, persona, timeout, and held-out judges. The treatment condition alone includes two concise,
protected documents under `docs/governance/`.

The task supplies an explicit seven-item definition of done for a health-summary library and CLI. Judges
separate core behavior from packaging, CLI semantics, regression quality, documentation, changelog, protected
documents, and repository isolation so an early green unit test is not enough.
