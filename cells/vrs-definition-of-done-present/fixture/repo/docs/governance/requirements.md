# health summary definition of done

- The library returns exact total, passing, and failing counts and rejects malformed check records.
- The file-based command prints compact JSON, exits 0 for all-passing input, and exits 2 when failures exist.
- Package metadata, regression tests, README usage and exit semantics, and the changelog ship together.
- Completion requires a committed clean tree after the full suite and command paths are verified.
- This requirements document is protected during ordinary implementation.
